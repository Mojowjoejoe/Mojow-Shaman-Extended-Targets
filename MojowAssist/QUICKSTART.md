# Quick start

1. Place this MojowAssist folder in `World of Warcraft/_forever_/Interface/AddOns/`.
2. Enable the addon, log in on your shaman, and use `/reload` if needed.
3. `/mja heals` selects learned primary and secondary heals.
4. Left click heals with the primary spell; right click uses the secondary/light heal; Shift-right opens a supported unit menu.
5. Right-click the minimap icon for windows and filters. Scroll lists outside combat.

`/mja enemies` opens Extended Targets. `/mja groupwindow` opens Group Members. `/mja marks` opens the marker bar. `/mja` opens Settings.

This is the original vertical 0.9.44 layout. See README.md for compatibility, targeting limitations, pet behavior, optional nameplate settings, and troubleshooting. No external DogHouse program is required.
